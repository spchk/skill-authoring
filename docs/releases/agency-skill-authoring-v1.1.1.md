# agency-skill-authoring 1.1.1

Небольшое обновление: правило о том, куда попадает навык.

## Что нового

- **Питфолл «услуга или продукт — отдельный приватный репозиторий».** Общая библиотека команды нужна
  для навыков, которыми пользуются все сотрудники. Всё, что относится к отдельной услуге или продукту
  (кодбук под нишу, коммерческие материалы, цифры клиентов, экономика), живёт в отдельном приватном
  репозитории с точечным доступом: в организации с `default_repository_permission: none` его видят
  только явно добавленные участники.

## Обновление

```bash
hermes skills tap add spchk/skill-authoring   # если ещё не подключён
hermes skills update agency-skill-authoring
```

Или копированием: `git pull` в клоне и `bash scripts/install.sh --agent hermes --force`.

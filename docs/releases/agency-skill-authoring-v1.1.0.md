# agency-skill-authoring 1.1.0 — первый публичный выпуск

Навык для ИИ-агентов: как превратить рабочий процесс в навык — от текста `SKILL.md` до публичного
репозитория с версиями, релизами и CI.

## Что вы получите

- **Три контура хранения** — личный каталог агента, приватный репозиторий команды, публичный
  репозиторий на рынок: что обязательно в каждом.
- **Каркас `SKILL.md`** — порядок секций с формулировками: триггеры, границы, требования к среде с
  фолбеком, артефакты между шагами, гейты на побочных эффектах.
- **Версии и обновления** — `version` в шапке навыка, `CHANGELOG.md`, релизы тегом
  `<имя-навыка>-v<версия>`, скрипт, который сверяет установленную версию с репозиторием.
- **Проверка требований до запуска** — preflight-скрипт: ключи (только маской), живой пробный вызов
  моделей, баланс, наличие бинарников, оценка стоимости работы. Блокер — то, без чего задача не
  будет сделана вообще; при блокере работа не начинается.
- **Упаковка и валидация** — упаковщик останавливается на секретах, а не выкидывает их молча;
  чек-лист перед публикацией наружу (внутренние пути, имена клиентов, идентификаторы кабинетов).
- **Внешний релиз** — лицензия и обязательства, раскладка публичного репозитория, ветки `main`/`dev`,
  правила PR, релизные заметки для пользователей, CI и релиз по тегу.

## Установка

```bash
hermes skills tap add spchk/skill-authoring
hermes skills install agency-skill-authoring
```

Или копированием: `git clone`, затем `bash scripts/install.sh --agent hermes`.

## Что проверено

- упаковщик: `package_skill.py --target hermes --public-check --strict-public --check` — чисто;
- CI репозитория проходит на каждом коммите в `main`;
- версия навыка и история — в `skills/agency-skill-authoring/`.

## Известные ограничения

- Примеры в справочниках взяты из практики автора (Hermes-агенты, русскоязычные процессы) — при
  переносе в другую команду меняйте контекст, а не структуру;
- для Claude Code и других агентов лишние поля фронтматтера (`version`, `category`) игнорируются
  загрузчиком — они нужны нашему контуру версионирования.

# История изменений репозитория `skill-authoring`

Версии навыка живут в шапке `skills/agency-skill-authoring/SKILL.md`, подробные записи — в
`skills/agency-skill-authoring/CHANGELOG.md`. Здесь — короткая история репозитория, релиз за релизом.

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — semver.
Тег релиза: `<имя-навыка>-v<версия>`.

## [1.1.1] — 2026-10-09

Добавлено:

- питфолл «услуга или продукт — отдельный приватный репозиторий, а не общая библиотека»;
- релизные заметки для пользователей: `docs/releases/agency-skill-authoring-v1.1.1.md`.

## [1.1.0] — 2026-10-09

Первый публичный выпуск.

Добавлено:

- навык `agency-skill-authoring` 1.1.0: три контура хранения навыков, каркас `SKILL.md`, упаковка и
  валидация, внешний релиз, питфоллы;
- раздел «Версии, обновление и проверка требований» и справочник
  `references/versioning-and-preflight.md`: версия в шапке навыка, `CHANGELOG.md`, релизы по тегам,
  скрипт сверки версии с репозиторием, preflight-проверка окружения и моделей до запуска
  (ключи с маской, живой пробный вызов модели, баланс, оценка стоимости);
- скрипты `new_skill.py` (каркас для трёх контуров), `package_skill.py` (упаковка, проверка на
  секреты и внутренний контекст), `sync_skills.py` (перенос навыка в репозиторий команды);
- README на русском и английском, MIT, CI и релизный воркфлоу, `install.sh` для шести агентов.

Ограничения первого выпуска: навык описывает практику на примере Hermes-агентов, часть примеров
привязана к рабочему процессу автора.

# skill-authoring — как создавать, упаковывать и публиковать навыки ИИ-агентов

Навык для тех, кто превращает рабочий процесс в навык ИИ-агента: от текста `SKILL.md` до
публичного репозитория с версиями, релизами и CI. Собран на практике агентства «Спички» —
внутренние навыки для агентов команды и публичные навыки для рынка.

Работает в Hermes Agent, OpenClaw, Claude Code, Cline, Cursor, Codex. Лицензия MIT.

## Что внутри

- **Три контура хранения** — личный каталог агента, приватный репозиторий команды, публичный
  репозиторий на рынок: что обязательно в каждом и почему «сначала личное, потом решим» — плохой
  ответ по умолчанию.
- **Каркас `SKILL.md`** — порядок секций с формулировками: когда триггерится, границы, что нужно от
  среды с веткой «если нет», артефакты между шагами, гейты на побочных эффектах.
- **Версии, обновление и проверка требований** — `version` в шапке навыка, `CHANGELOG.md`, релизы
  тегом `<имя-навыка>-v<версия>`, скрипт сверки версии с репозиторием и preflight-проверка окружения
  и моделей **до** запуска (ключи, живой пробный вызов модели, баланс, оценка стоимости).
- **Упаковка и валидация** — упаковщик, который останавливается на секретах, а не выкидывает их
  молча, плюс чек-лист перед публикацией наружу (внутренние пути, имена клиентов, id кабинетов).
- **Внешний релиз** — лицензия и её обязательства, раскладка публичного репозитория, ветки
  `main`/`dev`, правила PR, релизные заметки для пользователей, CI и релиз по тегу.

## Быстрый старт

Попросите агента:

```
сделай навык для команды: разбор звонков клиентов в сводку решений
оформим наш процесс как навык — что кладём в репозиторий, что нет
проверим, можно ли этот навык публиковать наружу
```

На выходе: папка навыка по канону, отчёт по секретам и внутреннему контексту, готовые команды
ветки, коммита и PR, а для внешнего контура — README на двух языках, LICENSE, CI и релизный воркфлоу.

## Скрипты

| скрипт | что делает |
|---|---|
| `scripts/new_skill.py` | каркас навыка для одного из трёх контуров (`personal` / `internal` / `external`) |
| `scripts/package_skill.py` | упаковка и валидация: секреты, переносимость, `--public-check` перед публикацией |
| `scripts/sync_skills.py` | перенос навыка из личной библиотеки в репозиторий команды + валидатор |

## Установка

### Hermes Agent (tap)

```bash
hermes skills tap add spchk/skill-authoring
hermes skills install agency-skill-authoring
```

### Копированием

```bash
git clone https://github.com/spchk/skill-authoring.git
cd skill-authoring
bash scripts/install.sh --agent hermes      # или --dir ~/my/skills
```

Скрипт раскладывает `skills/*` в каталог навыков агента
(`--agent hermes|openclaw|claude|cline|codex|cursor`). После установки нужен перезапуск сессии агента.

### Другие агенты

Навык — это обычный `SKILL.md` со справочниками и Python-скриптами: папку
`skills/agency-skill-authoring/` можно положить в каталог навыков любого агента, который читает
этот формат.

## Версии и релизы

Версия навыка — в шапке `skills/agency-skill-authoring/SKILL.md`, история — в `CHANGELOG.md` рядом с
ним. Релизы помечаются тегом `<имя-навыка>-v<версия>`:

```bash
gh release list
gh release view agency-skill-authoring-v1.1.0
```

Текущая версия — **1.1.0**.
